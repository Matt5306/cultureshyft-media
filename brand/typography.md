# Typography

One typeface family: **Manrope** (free, SIL Open Font License, commercial use allowed). Download: https://fonts.google.com/specimen/Manrope. In Canva it is available by name. In code: `font-family: "Manrope", "Segoe UI", system-ui, -apple-system, sans-serif;`

Why Manrope: geometric, friendly, reads well small, and it is the typeface the wordmark is cut from, so headings and the logo feel like one voice.

## Weights
- **ExtraBold 800**: the wordmark, headlines, numbers that matter.
- **Bold 700**: subheads, buttons, labels in caps with letter-spacing.
- **Medium 500**: body text, captions.
- Never Light or Thin: they disappear on phones and on print.

## Scale (web, in px; print in pt is the same number × 0.75)
| Role | Size | Weight | Notes |
|---|---|---|---|
| Display | 64–96 | 800 | letter-spacing −2%, line-height 1.0 |
| H1 | 40–48 | 800 | letter-spacing −1%, line-height 1.1 |
| H2 | 28–32 | 800 | line-height 1.2 |
| H3 | 22 | 700 | |
| Body | 17–18 | 500 | line-height 1.5, max 65 characters per line |
| Caption / label | 13–14 | 700 | ALL CAPS, letter-spacing +8% |
| Button | 17 | 700 | |

## Rules
- Caps + letter-spacing is for short labels only (MEDIA, FLYERS · SOCIAL · CAMPAIGNS). Never set a paragraph in caps.
- Headlines left-aligned by default. Centered only on posters and social squares.
- One size jump between levels is enough. If something needs to be louder, make it orange, not bigger.
