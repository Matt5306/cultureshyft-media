# CultureShyft Media — brand kit

The complete identity for **CultureShyft Media** (Mark Andrew, Cultural Media Artifact Engineer: flyers, social, campaigns, logos, websites). Everything here is final-quality and ready to hand to a printer, a web developer, another AI, or a business partner. Site: https://cultureshyftmedia.com

Mark: **The Y**. The odd letter in *Shyft* is a broadcast antenna. Tagline: **Media made to move people.**
Accent: Shyft Orange `#FF5A1F`. Ink: `#14151A`. Type: Manrope (free, SIL Open Font License; in `fonts/`).

## Start here
1. `brand/CultureShyft-Media-Brand-Guidelines.pdf`: the 10-page guide. Read it once.
2. `brand/CultureShyft-Media-Cheat-Sheet.pdf`: one page to keep open.
3. `brand/kit-guide.md`: how to use these files in Canva, Google Docs, and with an AI.
4. `brand/brand-prompt.md`: paste into any AI before asking it for brand work.

## Folders
| Folder | What is in it |
|---|---|
| `logo/svg/` | Vector masters: 4 lockups × 4 colorways, text as outlines. Use these for anything. |
| `logo/pdf/`, `logo/png/`, `logo/web/` | Same lockups as vector PDF, 300 DPI transparent PNG, and 1200 px web PNG. |
| `logo/icons/` | App icons 16–1024 px (light and dark tiles), 1080 px social avatars, `favicon.ico`. |
| `brand/` | Guidelines PDF, cheat sheet, colors, typography, logo rules, brand voice, brand story, bios, pricing, services, outreach scripts, kit guide, AI prompt. |
| `templates/print/` | Business card front/back (3.5×2 in + bleed), letterhead, invoice, flyer template, 6×4 postcard, 3 in sticker. Print-ready PDF. |
| `templates/social/` | Instagram posts (3 layouts) and stories (3), highlight covers (5), Facebook/LinkedIn/X/YouTube covers and posts. |
| `templates/digital/` | Zoom background, phone wallpaper, email header. `templates/email-signature.html` pastes into Gmail. |
| `templates/canva/` | Transparent 2000 px PNGs of every lockup for Canva. |
| `assets/` | Headshot, QR code to the site. |
| `fonts/` | Manrope variable font and license note. |
| `docs/` | The website (GitHub Pages at cultureshyftmedia.com). |
| `tools/` | Scripts that regenerate everything: `bash tools/export.sh`, `python tools/build_templates.py`, `python tools/build_extras.py`, `python tools/build_guidelines.py`. |

Logo file names: `cultureshyft-<horizontal|stacked|mark|wordmark>-<color-onlight|color-ondark|mono-black|mono-white>.<svg|pdf|png>`.
