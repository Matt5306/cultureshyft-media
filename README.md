# CultureShyft Media — brand kit

The complete identity for **CultureShyft Media** (Mark Andrew: flyers, social, campaigns). Everything here is final-quality and ready to hand to a printer, a web developer, another AI, or a business partner.

Mark: **The Y**. The odd letter in *Shyft* becomes a broadcast antenna. The spelling is the brand.
Accent: orange `#FF5A1F`. Ink: `#14151A`. Type: Manrope (free, SIL Open Font License).

## Folders

| Folder | What is in it |
|---|---|
| `logo/svg/` | Vector masters. 4 lockups × 4 colourways, text as outlines (no fonts needed). Use these for anything. |
| `logo/pdf/` | The same as vector PDF, for printers who ask for PDF. |
| `logo/png/` | 300 DPI transparent PNGs, for DTG/DTF printers and documents. |
| `logo/web/` | 1200 px PNGs for websites, slides, email. |
| `logo/icons/` | App icons 16–1024 px (light and dark tiles), 1080 px social avatars, `favicon.ico`. |
| `brand/` | Colours, type, logo rules, brand voice, the AI handoff prompt. (next) |
| `templates/` | Business card, letterhead, flyer, social sizes, email signature. (next) |
| `site/` | The brand guide website, served at cultureshyftmedia.com. (next) |
| `tools/` | The scripts that generated all of this; rerun `bash tools/export.sh` after a change. |

## Lockups and colourways

Lockups: `horizontal` (mark + wordmark), `stacked` (mark above wordmark), `mark` (the Y alone), `wordmark` (name alone).
Colourways: `color-onlight` (for white/light backgrounds), `color-ondark` (for dark backgrounds), `mono-black`, `mono-white` (one-colour print, embroidery, engraving).

File name pattern: `cultureshyft-<lockup>-<colourway>.<svg|pdf|png>`.
